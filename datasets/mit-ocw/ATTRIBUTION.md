# MIT OpenCourseWare attribution and data reuse

This directory contains a project-selected and normalized subset of historical course metadata from [MIT OpenCourseWare](https://ocw.mit.edu/), Massachusetts Institute of Technology. Each record in `catalog.json` identifies its course page, the instructors credited on that page, teaching year and license link. The project selected course records, converted descriptions to plain text, normalized some identifiers and topics, and added project-maintained prerequisite classifications.
