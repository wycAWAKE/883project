# MIT OpenCourseWare catalogue snapshot

This snapshot contains 444 historical MIT OpenCourseWare records selected and normalized for the SmartCampus non-commercial educational prototype. Each row in [catalog.json](catalog.json) credits its original course and instructors and includes links to the source and licence. The original course pages and syllabi remain at MIT OCW. Source fingerprints are retained for traceability.

See [attribution and reuse](ATTRIBUTION.md). The project selected and reformatted the metadata and added project-maintained prerequisite classifications. MIT does not endorse SmartCampus. Applicable OCW data is shared under [CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/), subject to separately marked rights. The software is separate from the OCW dataset.

There are 21 structured records, 10 with no formal course prerequisites, and 413 requiring review. Java excludes the review-required records from recommendations. Prerequisite groups use AND across groups and OR within each group. The historical material does not represent current enrolment or verified student completions.

See the [database import and API instructions](../../docs/m2/README.md) for importing the catalogue.
