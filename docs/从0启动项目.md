# 高校宿舍管理系统从 0 启动指南

本文档按“完全从零开始”的顺序说明如何启动本项目。照着执行即可完成 MySQL、后端、前端、浏览器访问和停止服务。

## 1. 项目地址

GitHub 仓库：

```text
https://github.com/Szpiss/dormitory-manager-coursework
```

如果本机还没有项目，先克隆：

```bash
cd ~/javascript
git clone https://github.com/Szpiss/dormitory-manager-coursework.git
cd dormitory-manager-coursework
```

如果已经有本地项目，进入当前项目目录：

```bash
cd /Users/cuing/javascript/dormitory-coursework/dormitory-manager
```

## 2. 项目结构

## 3. 启动前检查环境

### 3.1 检查 Java

```bash
java -version
```

能看到 Java 版本即可。课程要求是 JDK 1.8，当前机器也可以用 JDK 17 运行，因为项目 Maven 配置按 Java 8 语法编译。

建议在 IntelliJ IDEA 里优先使用 JDK 17。项目已显式配置 Lombok 注解处理器，当前也已兼容 JDK 25；但如果你打开的是旧版本项目，IDEA 构建窗口可能出现下面错误：

```text
java: java.lang.ExceptionInInitializerError
com.sun.tools.javac.code.TypeTag :: UNKNOWN
```

通常不是业务代码写错，而是 Lombok 注解处理没有被正确加载。处理方式：

1. 打开 IntelliJ IDEA 顶部菜单 `File -> Project Structure`。
2. 在 `Project` 里把 `SDK` 改成 `homebrew-17` 或任意 JDK 17。
3. `Language level` 选择 `17`。
4. 点击 `Apply` 和 `OK`。
5. 回到 Maven 面板，点击刷新按钮，再运行 `SpringbootApplication`。

如果你使用的是本项目最新版本，保持 `springboot/pom.xml` 中的 Lombok 版本和 `maven-compiler-plugin` 注解处理器配置即可。

本机 JDK 17 路径为：

```text
/opt/homebrew/opt/openjdk@17/libexec/openjdk.jdk/Contents/Home
```

### 3.2 检查 Maven

```bash
mvn -v
```

如果能输出 Maven 版本，说明 Maven 可用。

### 3.3 检查 Node 和 npm

```bash
node -v
npm -v
```

能输出版本即可。

### 3.4 检查 MySQL

```bash
mysql -uroot -e "SELECT VERSION();"
```

如果提示连接失败，先启动 MySQL：

```bash
brew services start mysql
```

如果你的 MySQL root 有密码，命令要改成：

```bash
mysql -uroot -p
```

并且要修改后端配置文件：

```text
springboot/src/main/resources/application.properties
```

把这一行：

```properties
spring.datasource.password=
```

改成你的 MySQL root 密码。

## 5. 启动后端

后端端口是：

```text
9090
```

### 5.1 先检查 9090 是否被占用

```bash
lsof -nP -iTCP:9090 -sTCP:LISTEN
```

如果没有输出，说明 9090 没有被占用。

如果有输出，例如：

```text
java  12345  cuing  ...  TCP *:9090 (LISTEN)
```

说明已有 Java 后端进程占用 9090。为了避免启动到旧项目或旧版本，先停止它：

```bash
kill 12345
```

如果普通 `kill` 停不掉，再用：

```bash
kill -9 12345
```

注意把 `12345` 换成你自己查出来的 PID。

### 5.2 用 IntelliJ IDEA 启动后端

推荐方式：

1. 打开 IntelliJ IDEA。
2. 选择 `Open`。
3. 打开这个目录：

```text
/Users/cuing/javascript/dormitory-coursework/dormitory-manager/springboot
```

4. 等 Maven 自动加载完成。
5. 打开文件：

```text
src/main/java/com/example/springboot/SpringbootApplication.java
```

6. 点击 `main` 方法左边或顶部的绿色运行按钮。

启动成功标志：

```text
Tomcat started on port(s): 9090
<================启动成功====================>
```

### 5.3 用命令行启动后端

也可以不用 IDEA，直接运行：

```bash
cd /Users/cuing/javascript/dormitory-coursework/dormitory-manager/springboot
mvn spring-boot:run
```

保持这个终端不要关闭，后端就会一直运行。

### 5.4 验证后端是否正常

执行：

```bash
curl -s -H 'Content-Type: application/json' \
  -X POST http://localhost:9090/admin/login \
  -d '{"username":"admin","password":"123456"}'
```

如果返回：

```json
{"code":"0","msg":"成功",...}
```

说明后端正常。

如果返回 404，通常说明 9090 上跑的是旧进程或错误项目。解决方法：

```bash
lsof -nP -iTCP:9090 -sTCP:LISTEN
kill 查到的PID
cd springboot
mvn spring-boot:run
```

## 9. 常见问题

### 9.1 前端能打开，但登录失败

先检查后端是否启动：

```bash
lsof -nP -iTCP:9090 -sTCP:LISTEN
```

再测试后端接口：

```bash
curl -s -H 'Content-Type: application/json' \
  -X POST http://localhost:9090/admin/login \
  -d '{"username":"admin","password":"123456"}'
```

如果这里不返回成功，前端登录也不会成功。

### 9.2 后端接口返回 404

这是本机最容易遇到的问题：9090 被旧 Java 进程占着，当前项目没有真正启动。

解决：

```bash
lsof -nP -iTCP:9090 -sTCP:LISTEN
kill PID
cd /Users/cuing/javascript/dormitory-coursework/dormitory-manager/springboot
mvn spring-boot:run
```

### 9.3 后端启动报数据库连接失败

检查 MySQL 是否启动：

```bash
mysql -uroot -e "SELECT VERSION();"
```

检查数据库是否存在：

```bash
mysql -uroot -e "SHOW DATABASES LIKE 'dormitory';"
```

如果没有数据库，重新导入：

```bash
mysql -uroot < database/dormitory_mysql8.sql
mysql -uroot < database/test_data.sql
```

### 9.4 前端 8080 被占用

```bash
lsof -nP -iTCP:8080 -sTCP:LISTEN
kill PID
cd vue
npm run dev
```

### 9.5 IDEA Maven 一直加载

可以先用命令行验证：

```bash
cd springboot
mvn -DskipTests compile
```

如果命令行能编译，说明项目本身没问题，IDEA 里点击 Maven 面板的刷新按钮即可。

### 9.6 IDEA 运行时报 TypeTag UNKNOWN

报错示例：

```text
java: java.lang.ExceptionInInitializerError
com.sun.tools.javac.code.TypeTag :: UNKNOWN
```

这是 Lombok 注解处理没有正确执行导致的编译问题。当前项目已经在 `springboot/pom.xml` 中升级 Lombok 并显式配置 annotation processor。若仍然出现该错误，请在 `File -> Project Structure -> Project` 中把 Project SDK 改为 JDK 17，并点击 Maven 面板刷新。

如果仍然失败，可以先用命令行启动后端：

```bash
cd /Users/cuing/javascript/dormitory-coursework/dormitory-manager/springboot
mvn spring-boot:run
```
