# M5/M6 contribution and handoff

Module owner: Jianning Tan, according to the group allocation.

This branch adapts the earlier independent M5/M6 implementation to the group's Spring Boot 2.6.3 / Java 8 target and Vue framework. It preserves the group's login, Session, module routes and M1–M4 placeholders.

Delivered: request forms, supporting materials, staff review, returned-request revision, processing history, applicant notices, read-state controls, backend role/ownership checks, additive MySQL schema, isolated demo/test setup, 16 MySQL workflow tests, browser evidence and local startup instructions.

Group coordination still needed: review the documented stable account key and Administrator policy, agree on any future cross-module notification contract, and test against later changes from other members. This branch does not implement their module backends.

Publication uses the personal m5-m6-administration branch. No force push or main-branch overwrite is required. The prepared computer can run submit-to-group.cmd. It shows the staged summary, asks for a GitHub username for the commit's noreply address and then uses Git's normal authentication. Do not enter passwords or tokens into chat. The GitHub account must have write access to the group repository.

Private local credentials, runtime artifacts and backups are excluded. The source package is for development and needs the documented environment and database setup. The prepared local folder already contains its private runtime configuration and builds.
