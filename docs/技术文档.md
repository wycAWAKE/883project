# 高校宿舍管理系统技术文档

## 1. 项目概述

高校宿舍管理系统是一个面向学校宿舍业务场景的综合管理系统，主要解决宿舍基础信息维护、学生住宿分配、宿管日常管理、报修处理、调宿审核、水电费记录、卫生检查、公告发布、访客登记等问题。

项目采用前后端分离架构，后端基于 Spring Boot 2.x 开发 RESTful 接口，数据库使用 MySQL 8.0，前端使用 Vue 3 + Vite + Element Plus 构建后台管理界面。系统划分管理员、宿舍管理员、学生三种角色，并通过角色表、菜单表、角色菜单关联表实现不同角色的菜单权限配置。

本项目可作为课程大作业中的“其他管理系统”类型提交。若与“紫金学院管理系统”要求对应，可将宿舍楼理解为部门资源，房间理解为班级或资源分组，学生、宿管、管理员分别对应普通用户、管理教师、系统管理员。

## 2. 技术栈

| 层级 | 技术 | 说明 |
| --- | --- | --- |
| 后端 | Spring Boot 2.6.3 | 负责接口、业务逻辑、会话管理 |

| 前端 | Vue 3 + Vite | 前端工程化和页面开发 |

| 开发工具 | IntelliJ IDEA | 后端推荐启动方式 |

## 3. 系统架构

系统采用浏览器、前端、后端、数据库四层结构：

```text
浏览器
  |
  | 访问 http://localhost:8080
  v
Vue 3 + Vite 前端
  |
  | axios 请求 /api 或代理到后端接口
  v
Spring Boot 后端 http://localhost:9090
  |
  | MyBatis-Plus / JdbcTemplate
  v
MySQL 8.0 数据库 dormitory
```

前端负责页面展示、表单校验、路由跳转、菜单渲染。后端负责登录认证、Session 保存、业务数据处理、分页查询、权限菜单查询。数据库负责持久化保存系统数据。

## 5. 数据库设计

数据库名称为 `dormitory`，字符集使用 `utf8mb4`，兼容 MySQL 8.0。

### 5.1 用户与角色相关表

| 表名 | 说明 |
| --- | --- |
| `admin` | 系统管理员账号表 |
| `student` | 学生账号表 |
| `dorm_manager` | 宿舍管理员账号表 |
| `sys_role` | 角色表 |
| `sys_menu` | 菜单权限表 |
| `sys_role_menu` | 角色菜单关联表 |

`admin` 主要字段：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `username` | varchar | 管理员账号，主键 |
| `password` | varchar | 密码 |
| `name` | varchar | 姓名 |
| `gender` | varchar | 性别 |
| `age` | int | 年龄 |
| `phone_num` | varchar | 手机号 |
| `email` | varchar | 邮箱 |
| `avatar` | varchar | 头像地址 |

`student` 主要字段与 `admin` 类似，用于保存学生基本信息。

`dorm_manager` 额外包含 `dormbuild_id`，表示该宿管负责的宿舍楼编号。

### 5.2 宿舍基础数据表

| `dormbuild_id` | int | 楼宇编号 |

`dorm_room` 字段：

| 字段 | 类型 | 说明 |
| --- | --- | --- |

| `max_capacity` | int | 最大入住人数 |
| `current_capacity` | int | 当前入住人数 |
| `first_bed` | varchar | 一号床学生账号 |
| `second_bed` | varchar | 二号床学生账号 |
| `third_bed` | varchar | 三号床学生账号 |
| `fourth_bed` | varchar | 四号床学生账号 |

| 表名 | 说明 |
| --- | --- |

| `visitor` | 访客登记表 |

| `dorm_electric` | 电费记录表 |

这些表覆盖宿舍管理中的常见业务流程，支持后台管理系统演示和课程报告编写。

### 5.4 权限表设计

`sys_role` 保存角色：

| role_code | role_name | 说明 |
| --- | --- | --- |
| admin | 系统管理员 | 拥有全部菜单和管理权限 |
| dormManager | 宿舍管理员 | 负责宿舍日常管理 |
| stu | 学生 | 查看个人信息，提交申请 |

`sys_menu` 保存菜单：

| 字段 | 说明 |
| --- | --- |
| `parent_id` | 父级菜单 ID，0 表示一级菜单 |
| `menu_name` | 菜单名称 |
| `menu_path` | 前端路由地址 |
| `icon` | Element Plus 图标名称 |
| `sort_num` | 排序值 |
| `menu_type` | catalog 或 menu |
| `permission_code` | 权限标识 |
| `description` | 菜单说明 |

`sys_role_menu` 保存角色与菜单的多对多关系。前端侧边栏会通过 `/permission/menus` 接口获取当前登录角色可访问的菜单。

## 6. 角色权限设计

系统共三种角色：

### 6.1 系统管理员

管理员拥有全部管理权限，包括：

- 学生信息管理
- 宿管信息管理
- 楼宇信息管理
- 房间信息管理
- 公告管理
- 报修管理
- 调宿审核
- 访客管理
- 水费管理
- 电费管理
- 卫生检查
- 权限说明查看
- 个人信息维护

### 6.2 宿舍管理员

宿舍管理员用于模拟教师或管理人员角色，主要负责日常宿舍事务：

- 学生信息查看与维护
- 楼宇、房间信息查看
- 报修工单处理
- 调宿申请审核
- 访客登记
- 卫生检查
- 个人信息维护

### 6.3 学生

学生角色只保留个人业务功能：

- 查看首页
- 查看我的宿舍
- 提交调宿申请
- 提交报修申请
- 查看水电费记录
- 查看卫生检查记录
- 修改个人信息

## 7. 核心功能模块

### 7.1 登录模块

登录页面支持选择身份：学生、宿舍管理员、系统管理员。前端根据选择的身份调用不同接口：

| 身份 | 接口 |
| --- | --- |
| 学生 | `/stu/login` |
| 宿舍管理员 | `/dormManager/login` |
| 系统管理员 | `/admin/login` |

登录成功后，后端将用户信息和身份存入 Session，前端将用户信息和身份存入 `sessionStorage`，用于路由守卫和页面展示。

### 7.2 路由拦截

前端在 `vue/src/router/index.js` 中配置路由守卫。未登录用户访问后台页面时会跳转到登录页，已登录用户访问根路径时会跳转到首页。

### 7.3 动态菜单渲染

侧边栏组件 `Aside.vue` 会调用：

```text
GET /permission/menus
```

后端根据 Session 中的 `Identity` 查询 `sys_role_menu` 和 `sys_menu`，返回树形菜单。前端根据返回结果渲染一级菜单和二级菜单。

### 7.4 学生管理

管理员和宿管可以维护学生账号，支持分页查询、新增、编辑、删除。学生账号也用于宿舍床位分配、报修申请、调宿申请等业务。

### 7.5 宿管管理

管理员可以维护宿舍管理员账号，包括宿管账号、密码、负责楼宇、姓名、联系方式等信息。

### 7.6 楼宇与房间管理

楼宇管理维护宿舍楼基础信息。房间管理维护房间号、楼宇号、楼层、最大容量、当前入住人数以及床位学生账号。系统可根据床位信息查询学生所在宿舍。

### 7.7 报修管理

学生可以提交报修申请，管理员和宿管可以查看和处理报修工单。报修工单包含标题、内容、宿舍楼、房间号、申请人、状态、创建时间和完成时间。

### 7.8 调宿管理

学生可以申请调宿，填写目标房间和床位。管理员或宿管审核后，可以通过或驳回申请。通过时系统会更新原房间和目标房间的床位信息。

### 7.9 水电费管理

水费、电费模块用于记录宿舍费用操作。管理员可以对指定房间扣费，学生可对自己所在宿舍充值。系统保存操作人、房间号、类型、金额、时间。

### 7.10 卫生检查

宿管或管理员可以登记卫生检查结果，学生可查看自己宿舍的检查情况。检查内容包括宿舍号、结果、说明、操作人和时间。

### 7.11 权限说明

新增 `PermissionInfo.vue` 页面，用于展示系统角色和菜单权限矩阵，方便课程验收时说明角色权限控制的实现方式。

### 7.12 移动端与 PC 端适配

系统默认是 PC 后台布局。在移动端宽度下：

- 登录页图片和表单垂直排列；
- 侧边栏变为顶部横向滚动菜单；
- 表格容器支持横向滚动；
- 弹窗宽度自动调整为屏幕宽度的 92%；
- 表单控件在小屏下改为 100% 宽度。

该适配可满足课程中“移动端、PC 端双端适配”的加分要求。

## 13. 项目特色

1. 完成 Spring Boot + MySQL 8.0 + Vue 3 + Vite 技术栈适配。
2. 覆盖管理员、宿管、学生三种角色。
3. 实现数据库级菜单权限配置。
4. 菜单支持按角色动态渲染。
5. 业务功能贴近宿舍管理真实场景。
6. 提供可重复导入的测试数据脚本。
7. 支持 PC 端和移动端基础适配。

## 14. 可改进方向

1. 后端可进一步加入统一拦截器，对每个接口进行服务端权限校验。
2. 密码可改为加密存储，例如 BCrypt。
3. 权限管理可扩展为页面可配置，而不是只通过 SQL 初始化。
4. 调宿审核可加入操作日志。
5. 移动端可进一步拆分为专门的小程序或移动 Web 页面。
