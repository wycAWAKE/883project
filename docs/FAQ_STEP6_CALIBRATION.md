## 测量前冻结的判断标准

| 标签/状态 | 判断标准 | 后续预期行为 |
| --- | --- | --- |
| answerable | 冻结语料明确包含用户所问事实，expectedKeys指明可接受证据 | 达到接收条件后才允许回答；保留版本和事实限制 |
| no_match | 没有所问事实，包括相近主题但缺失当前费用/条件、个人信息、超出资料范围或业务执行能力 | 无匹配指引，不能用相似主题补造事实 |
| clarify | 缺少唯一话题/指代且没有提供历史 | 先澄清，不能把相似度高低当成指代解析；本批不改变现有C5规则 |
| unavailable | 服务/索引/网络发生故障，而非知识是否支持的标签 | 后续才实现与正常拒答明确区分的回退决策；故障样本不混入相似度指标 |

评估的是当前40条冻结语料的事实覆盖，不宣称校方当前政策完整或经过重新审核。旧指南的公开入口不等于现行费用/材料承诺，公开表单不等于个人证明签发服务，账号恢复指南不包含个人密码/PIN/余额。生成引用格式正确也不等于事实支持，实际生成质量留待后续验收。

## 测量与阈值选择规则（在运行前确定）

1. 使用同一轮固定BGE-M3/1024维输出，为40段公开问题+关键词及52个通用测试问题共92段文本生成向量。无数据库访问、不发送答案/账号/会话信息、不调用DeepSeek；8道澄清题和全部holdout问题不发送。
2. 全部查询对全部40条知识计算cosine，保存52×40完整矩阵、稳定的分数降序/key升序排名、正确知识位置和Top1/Top3。实验不使用TF-IDF前置过滤。每个候选分别应用`score >= threshold`后再取最多3个。
3. 比较原TF-IDF0.35、当前步骤5“词法准入+BGE排序”、无接收阈值的BGE候选排名及100个独立BGE阈值（0.01至1.00、步长0.01）。这两个不同检索器的数值不按同一概率解释。
4. 分开记录正例首位正确接收、正例错误首位接收、负例错误接收、正例被拒绝、Top3仍有正确资料，以及已接收但Top3全错。候选错误接收是风险指标，不是已经观察到生成幻觉。
5. 先要求调参集上负例错误接收和正例错误首位接收均为0；在满足这个约束的阈值中选首位正确接收最多的，平局选最小阈值。如果没有可行值，明确无候选；如果只能全部拒答，明确零有效覆盖，不能称为解决问题。
6. 同时比较正例保留程度与原基线；候选只用于离线实验，不能直接写入运行配置。独立集、真实生成与策略异常回退均未验收前，不自动开启纯语义接收。相近知识分数重叠时先报告反例，后续再判断是否调整知识表示/条目边界。

## 能解释阈值取舍的反例

- `S6N02`问补办毕业证明当前材料，只有表单列表的`CCNU-FAQ-010`仍得到0.72737；它不能据此承诺当前材料要求。
- `S6N06`问实际校园卡PIN，PIN重置指南得分0.72312；指南不含任何真实PIN。
- `S6N11`问临时网络账号是否保证一小时开通，相关申请指南得分0.71800；没有这项时限保证。
- `S6P20`问恰好10人团体预约博物馆，正确知识首位仅0.61041。冻结语料明确支持人数边界和预约提前量，但0.73会把它拒绝。
- 原`C04`（WeCom注册手机号登录）首位仍为移动端一网通办入口，0.67237；正确知识在第二位。不能只看Top3而忽略直接摘录首位时的风险。

这组分数重叠足以说明：继续开发时应区分“是否找到相关证据”和“证据是否包含请求事实”，不能靠提高一个阈值完成全部拒答目标。本批不据结果改题、改标签、扩写语料或加针对题号的规则。
