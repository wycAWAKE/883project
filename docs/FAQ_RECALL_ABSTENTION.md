## 改了什么

旧模式用同一个向量阈值在生成前过滤证据，容易同时丢掉同义问题。现在分开候选召回与标准答案准入：

| 设置 | 默认及作用 |
| --- | --- |
| `faq.embedding.semantic-acceptance-enabled` | false；保留原词法准入+BGE排序 |
| `faq.embedding.semantic-threshold` | 0.73；未启用生成时，语义标准答案仍需达到此门槛 |
| `faq.embedding.candidate-threshold` | 缺省沿用上项；仅语义模式且生成启用时收集最多3个模型候选 |

要求有限数值且 `0 < candidate <= semantic <= 1`。旧构造器保持原门槛，旧固定40题工具显式固定两项均为0.73，历史报告和调用账本不变。

语义模式中，低分候选不能直接显示为 Stored answer。正常空候选、模型明确资料不足、网络或无效输出、父超时都保留无答案备用结果；向量不可用时可以将达到旧词法门槛的资料交给模型，但生成成功前不发布摘录。生成关闭时仍走原语义门槛和既有不可用回退。数据库异常不变成正常拒答。默认词法模式保留原摘录降级顺序。

生成提示现在区分公开找回/重置流程与秘密值，同义表达不要求字面完全重合；文档或网站入口问题可以返回受支持的文字指引，由 Sources 提供链接。没有所需版本、费用、个人值时仍拒答；请求实际执行或确认账号更新、预约、文件恢复等操作明确返回资料不足，支持的操作指引仍可回答。继续严格校验引用和正文链接，没有增加重试、重排服务或第二次充分性调用。
