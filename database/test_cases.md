# 宿舍管理系统测试数据说明

## 导入方式

```bash
mysql -uroot < database/test_data.sql
```

该脚本可重复执行，会先删除自己创建过的测试数据，再重新插入。

## 建议测试场景

1. 管理员登录后查看学生、宿管、楼宇、房间列表，搜索 `测试`、`三号`、`301`。
2. 打开公告管理，查看三条 `测试-` 开头公告，并尝试新增、编辑、删除一条公告。
3. 打开报修管理，按标题搜索 `空调` 或 `水龙头`，测试未完成和已完成状态。
4. 打开水费、电费管理，按房间号 `301`、`302` 搜索，测试充值和扣费记录。
5. 打开卫生检查，查看 `优秀`、`良好`、`待改进` 三类结果。
6. 打开调宿审核，处理 `test_stu01` 的未处理申请，选择通过或驳回。
7. 学生 `test_stu01` 登录，进入我的宿舍、报修申请、调宿申请页面，提交一条新申请。
